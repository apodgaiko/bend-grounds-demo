      Agent API

      The game is a pure function of seed and move list, computed by the native Bend server. Agents and this page use the same endpoint; there is no session state.

      Endpoints

      GET /api/rulesUnits, tribes, tiers, costs and action grammar (JSON).
      GET /api/game?v=3&seed=S&moves=MReplays comma-separated moves M from seed S; returns the observation for the acting seat including legalActions.
      GET /api/healthLiveness.

      Move grammar

      0-based indexes. Protocol 3: buy:i (shop slot → your hand), play:i (hand card → right end of the warband, resolving its play effects), sell:i (warband slot; hand cards cannot be sold), swap:i:j (reorder the warband), roll, freeze, upgrade, invest, end, auto. Only the warband fights. end lets the bots act, resolves combat, and opens the next round. Only strings in legalActions are accepted; anything else returns a structured error and no state change. Three plain copies of one card across hand and board merge into a golden copy (every unit has golden; board units report their total sellGold).

while True:
    s = GET("/api/game?v=3&seed=42&moves=" + ",".join(moves))
    if s["phase"] == "finished": break
    moves.append(choose(s["legalActions"], s))   # your policy
      
        
      Modes and self-play
      
        
      mode=bots (default): you act for seat 0, built-in Bend bots act for seats 1–3 when you send end. mode=manual: every seat is driven by the move list; player tells you which seat acts next, so one agent can play all seats (self-play) or several agents can share one transcript. The move auto asks the built-in bot to play the acting seat's turn.
      
        
      Errors
      
        
      Two kinds, both non-2xx JSON with an error object holding at least code and message:
      
        
        
          
      • Request-level (bad_request for a bad seed or mode, too_many_moves, unknown route → 404): error only, with no game state and no index/move.
        • 
          
      • Action-level (bad_move for unparseable strings, illegal_move for moves not legal now): HTTP 400 with the full observation before the failing move plus error.index and error.move; movesApplied counts the accepted prefix. Later moves are ignored.
        • 
        
      
        
      Observations hide other seats' shops, gold, frozen state and hand contents (only handCount is public), and the RNG. The latest round's combat[].events list every attack with before/after board snapshots; the battle viewer replays them without computing anything.
      
        
      See docs/ in the repository for the full specification and proof notes.
